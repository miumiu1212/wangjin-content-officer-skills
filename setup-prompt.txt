【部署步骤】

────────────────────────────────────────

步骤 1 · 获取代码

1) 检查是否有 git：git --version
   - 若有 git：git clone https://github.com/miumiu1212/wangjin-content-officer-skills.git
   - 若无 git：curl 下载 GitHub 仓库 zip（默认分支 main），解压到工作目录
2) 进入仓库根目录：cd wangjin-content-officer-skills

步骤 2 · 确认 skill 文件结构

执行以下检查，确认 4 个 skill 文件夹均存在且包含 SKILL.md：

```
ls -la 网金内容官/SKILL.md
ls -la 网金内容官/references/platform-specs.md
ls -la 网金内容官/references/style-presets.md
ls -la 网金内容官/references/outline-template.md
ls -la 网金内容官/references/compliance-rules.md
ls -la 网金内容官/references/hot-topics-format.md
ls -la 今日热点/SKILL.md
ls -la 选题推荐/SKILL.md
ls -la 生成文章/SKILL.md
```

若有文件缺失，提示员工重新 clone 或检查仓库完整性。

步骤 3 · 配置环境（按需）

检查是否需要配置 .env 文件。本工作区的 skill 主要依赖：
- LLM 服务（由 WorkBuddy 提供，无需额外配置）
- 财联社数据接口（如需实时热点，需配置接口地址和密钥）

创建 .env 文件（如需）：
```
cp .env.example .env（如有模板）
```

或手动创建 .env：
```
# 财联社接口配置（如需实时热点）
CLS_API_BASE_URL=https://www.cls.cn
CLS_API_KEY=（联系管理员获取，或留空使用缓存模式）

# 缓存配置
HOT_TOPICS_CACHE_DIR=cache/hot-topics
HOT_TOPICS_CACHE_TTL=7200

# 草稿存储路径
DRAFTS_DIR=drafts
```

若员工暂无财联社 API Key，说明：skill 仍可使用缓存模式运行，热点数据每日定时更新；实时补充功能需配置 Key 后生效。

步骤 4 · 创建草稿目录

```
mkdir -p drafts
mkdir -p cache/hot-topics
```
