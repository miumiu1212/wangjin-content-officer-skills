# 热点数据格式规范

> 财联社热点数据结构、缓存格式、降级策略。`今日热点`子 skill 和主 skill Step 1 参照此文件。

---

## 数据源

### 主数据源

**财联社**（cls.cn）
- 接口：财联社电报/快讯 API
- 更新频率：实时滚动
- 内容：财经快讯、市场异动、政策发布、数据公布

### 降级数据源（未来扩展，本期不实现）

| 降级层级 | 数据源 | 说明 |
|---------|--------|------|
| 主源 | 财联社 API | 实时快讯 |
| 降级 1 | 财联社 RSS | 若 API 不可用，降级到 RSS |
| 降级 2 | 缓存数据 | 若实时都不可用，使用最近一次缓存 |
| 降级 3 | 空态 | 无数据时提示重试 |

## 热点数据结构

```json
{
  "fetch_time": "2026-08-20T08:00:00",
  "source": "财联社",
  "is_cached": false,
  "topics": [
    {
      "id": "cls_20260820_001",
      "title": "央行宣布下调 LPR 15 个基点",
      "summary": "中国人民银行今日宣布，1 年期 LPR 下调 15 个基点至 3.35%，5 年期下调至 3.85%。这是今年以来第三次下调。",
      "source": "财联社",
      "published_at": "2026-08-20T09:15:00",
      "tags": ["LPR", "央行", "降息", "房贷"],
      "importance": "high",
      "read_count": 125000,
      "category": "货币政策"
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| fetch_time | string | 数据获取时间（ISO 8601） |
| source | string | 数据来源标识 |
| is_cached | boolean | 是否为缓存数据 |
| topics | array | 热点列表 |
| topics[].id | string | 热点唯一 ID |
| topics[].title | string | 热点标题 |
| topics[].summary | string | 摘要（2-3 句话） |
| topics[].source | string | 来源（固定「财联社」） |
| topics[].published_at | string | 发布时间（ISO 8601） |
| topics[].tags | array | 标签列表（# 格式） |
| topics[].importance | string | 重要性：high / medium / low |
| topics[].read_count | number | 阅读量（用于排序） |
| topics[].category | string | 分类（货币政策/市场数据/行业动态等） |

## 缓存策略

### 定时缓存

| 时间 | 动作 |
|------|------|
| 每日 08:00 | 全量抓取并缓存 |
| 每日 12:00 | 增量更新缓存 |
| 每日 16:00 | 增量更新缓存 |

### 实时补充

- 员工触发 skill 时检查缓存时间
- 若缓存时间 > 2 小时，触发实时补充抓取
- 实时抓取成功后合并到缓存（新增的热点追加，已存在的更新）
- 实时抓取失败时使用缓存，标注 `is_cached: true` 和缓存时间

### 缓存存储

```
cache/
└── hot-topics/
    ├── 2026-08-20.json    # 今日缓存
    └── 2026-08-19.json    # 昨日缓存（可做历史对比）
```

## 热点筛选规则

### 从原始快讯到展示热点的筛选

1. **去重**：同一事件的多条快讯只保留最新一条
2. **排序**：按 importance + read_count 综合排序
3. **过滤**：排除非财经内容（如纯娱乐八卦）
4. **数量**：一次展示 5-8 条
5. **标签**：从快讯内容中提取 2-4 个关键标签

### 重要性判定

| 级别 | 判定条件 |
|------|---------|
| high | 头条快讯 / 涉及央行/国务院政策 / 市场重大异动（涨跌超 2%） |
| medium | 行业数据公布 / 上市公司重大公告 / 经济数据 |
| low | 个股动态 / 一般行业新闻 |

## 降级处理流程

```
员工触发获取热点
    │
    ├─ 检查缓存
    │   ├─ 缓存存在且 < 2 小时 → 直接使用缓存
    │   ├─ 缓存存在但 > 2 小时 → 尝试实时补充
    │   │   ├─ 实时成功 → 合并后使用
    │   │   └─ 实时失败 → 降级使用缓存，标注时间
    │   └─ 无缓存 → 尝试实时抓取
    │       ├─ 实时成功 → 使用并缓存
    │       └─ 实时失败 → 展示空态
    │
    └─ 展示结果
```

## 空态处理

当无数据可展示时：

```
📭 今日热点
━━━━━━━━━━━━━━━━━━
暂无热点数据

可能原因：
• 财联社接口暂时不可用
• 今日尚无重大财经快讯
━━━━━━━━━━━━━━━━━━
[🔄 重试]

💡 你也可以直接输入主题，跳过热点选择
```
