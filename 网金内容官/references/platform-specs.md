# 平台内容规范

> 各发布平台支持的内容类型、字数限制、格式要求。主 skill 和子 skill 生成大纲/文章时参照此文件适配。

---

## 抖音

### 支持的内容类型

| 类型 | 说明 | 字数参考 |
|------|------|---------|
| 短视频文案 | 视频配文，出现在视频下方 | 200-500 字 |
| 口播稿 | 视频中口述的完整稿件 | 300-800 字 |
| 标题+文案 | 标题（钩子）+ 正文文案组合 | 标题 ≤20 字，文案 200-500 字 |

### 平台特性

- **开头 3 秒原则**：文案/口播稿开头必须有钩子（提问/数字/反转/冲突）
- **口语化**：适合口语表达，避免书面语
- **Emoji 适量**：可使用 2-4 个 emoji 增加表达力，不宜过多
- **话题标签**：文末附 3-5 个 # 话题标签
- **禁止**：不能出现微信号、二维码导流；不能出现「点赞关注」以外的 CTA

### 抖音大纲结构（3-4 段）

```
一、开头钩子（提问/数字/反转）
二、核心内容（2-3 个要点）
三、互动引导（提问/投票/争议点）
四、（可选）总结金句
```

## 视频号

### 支持的内容类型

| 类型 | 说明 | 字数参考 |
|------|------|---------|
| 短视频文案 | 视频配文 | 200-500 字 |
| 图文 | 多图+文字说明 | 500-1000 字 |
| 口播稿 | 视频中口述稿件 | 300-800 字 |

### 平台特性

- **社交属性强**：内容会被微信好友看到，语气更正式
- **适合深度内容**：用户停留时间比抖音长，可适当增加深度
- **链接友好**：可附公众号文章链接
- **话题标签**：文末附 2-3 个 # 话题标签
- **禁止**：不能直接导流到外部平台

### 视频号大纲结构（3-5 段）

```
一、引入（热点事件/数据引入）
二、背景解读
三、核心分析（2-3 个要点）
四、实用建议
五、（可选）风险提示
```

## 小红书

### 支持的内容类型

| 类型 | 说明 | 字数参考 |
|------|------|---------|
| 图文笔记 | 标题 + 正文，配合图片发布 | 标题 ≤20 字，正文 300-1000 字 |
| 标题+正文 | 纯文字内容 | 同上 |

### 平台特性

- **标题是关键**：标题决定点击率，需要有吸引力但不过度标题党
- **分段清晰**：正文用短段落，每段 2-3 句，配合 emoji 分段
- **干货导向**：用户期待实用信息，内容需有「收藏价值」
- **话题标签**：文末附 5-8 个 # 话题标签
- **禁止**：不能出现微信号、手机号导流；不能出现「私信」「加我」等导流话术
- **Emoji 使用**：每个小标题前可加 1 个 emoji，段落间可用 emoji 分隔

### 小红书大纲结构（4-6 段）

```
一、引入（痛点/场景/数据）
二、核心知识点 1
三、核心知识点 2
四、核心知识点 3
五、实操建议/总结
六、（可选）互动引导
```

---

## 通用注意事项

- 所有平台内容不得包含明确个股推荐（合规要求）
- 涉及收益率、业绩的数据需标注来源
- 金融科普内容需包含风险提示
- 不同平台的大纲段落数不同，生成时需适配
