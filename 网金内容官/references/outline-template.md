# 大纲结构模板

> 不同平台/内容类型的大纲段落结构和要点格式。生成大纲时参照此模板选择对应结构。

---

## 通用大纲格式

```
一、[段落标题]
  • [要点 1：具体内容方向]
  • [要点 2：具体内容方向]
  • [要点 3（可选）：具体内容方向]

二、[段落标题]
  • [要点 1]
  • [要点 2]
```

**规则**：
- 每段 2-3 个要点
- 要点描述具体内容方向，不写完整句子（如「央行降息的三个原因」而非「央行降息的原因包括经济增速放缓、通胀压力减轻和外部环境变化」）
- 段落标题简明（≤15 字）

---

## 按平台适配的段落结构

### 抖音 · 短视频文案（3-4 段）

```
一、开头钩子
  • 吸引注意力的第一句（提问/数字/反转）
  • 引出话题

二、核心内容
  • 关键信息点 1
  • 关键信息点 2

三、价值输出
  • 读者能获得什么/怎么做

四、互动引导（可选）
  • 提问/投票/争议点
```

### 抖音 · 口播稿（3-4 段）

```
一、开场（3 秒钩子）
  • 抓住注意力的开场白
  • 交代视频要讲什么

二、主体内容
  • 核心观点 1（配数据/案例）
  • 核心观点 2（配数据/案例）

三、总结
  • 一句话总结核心观点
  • 金句收尾
```

### 视频号 · 短视频文案（3-5 段）

```
一、热点引入
  • 今日财经热点事件
  • 为什么值得关注

二、背景与解读
  • 事件背景
  • 关键数据

三、影响分析
  • 对市场的影响
  • 对普通人的影响

四、实用建议（可选）
  • 读者可以怎么做

五、风险提示（可选）
  • 需要注意的风险
```

### 视频号 · 图文（4-5 段）

```
一、引入
  • 热点事件/数据引入
  • 核心问题

二、分析展开
  • 分析维度 1
  • 分析维度 2

三、深度解读
  • 专家/机构观点
  • 历史对比

四、结论与建议
  • 总结要点
  • 可操作建议
```

### 小红书 · 图文笔记（4-6 段）

```
一、引入（痛点/场景）
  • 引发共鸣的场景或痛点
  • 本文要解决的问题

二、知识点 1
  • 核心概念解释
  • 通俗比喻

三、知识点 2
  • 核心概念解释
  • 通俗比喻

四、知识点 3（可选）
  • 核心概念解释
  • 通俗比喻

五、实操建议
  • 读者可以怎么做
  • 注意事项

六、互动引导（可选）
  • 提问引导评论
  • 收藏提示
```

## 大纲生成 prompt 模板

```
请基于以下信息生成文章大纲：

选题：{选题标题}
平台：{平台}
内容类型：{内容类型}
风格：{风格}

要求：
1. 大纲段落数参照 {平台} 的 {内容类型} 结构模板
2. 每段 2-3 个要点，要点描述内容方向不写完整句子
3. 段落标题简明（≤15 字）
4. 预计字数标注
5. 风格为「{风格}」，大纲的要点方向需匹配该风格特点

大纲结构参照：
{对应的模板}
```
