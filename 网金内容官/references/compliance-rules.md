# 合规规则清单

> 金融内容合规校验规则。文章生成后自动执行，命中风险时高亮提示但不阻断流程。

---

## 校验流程

1. 文章生成完成后，自动执行以下 4 类规则校验
2. 校验结果以标签形式附加在文章卡片下方
3. 校验不阻断流程——即使命中风险，员工仍可复制/保存
4. 若合规引擎本身执行失败，文章仍展示，提示「合规校验未执行，请人工复核」

---

## 规则 1：敏感词检测

### 金融法规禁用词

以下词汇在金融内容中禁止出现或需替换：

| 禁用词 | 风险等级 | 建议替换 |
|--------|---------|---------|
| 保本保息 | 🔴 高 | 不承诺保本，改为「低风险」 |
| 稳赚不赔 | 🔴 高 | 删除，改为风险提示 |
| 绝对收益 | 🔴 高 | 「预期收益」（需标注非保证） |
| 内幕消息 | 🔴 高 | 删除 |
| 荐股 / 推荐股票 | 🔴 高 | 「市场分析」（不涉及具体个股） |
| 跟单 | 🔴 高 | 删除 |
| 包赚 | 🔴 高 | 删除 |

### 绝对化用语

| 禁用词 | 风险等级 | 说明 |
|--------|---------|------|
| 100% / 百分之百 | 🟡 中 | 除非有数据支撑，否则不使用 |
| 一定 / 必然 / 肯定 | 🟡 中 | 改为「可能」「预计」 |
| 最好 / 最优 / 第一 | 🟡 中 | 除非有权威排名依据 |
| 稳了 / 稳了稳了 | 🟡 中 | 情绪化表达，需标注「个人观点」 |

### 承诺收益类

| 禁用表述 | 风险等级 | 说明 |
|---------|---------|------|
| 年化收益 XX% | 🔴 高 | 除非标注「历史业绩不代表未来」 |
| 月赚 XX 元 | 🔴 高 | 禁止承诺具体收益 |
| 收益翻倍 | 🔴 高 | 禁止承诺收益倍数 |
| 零风险 / 无风险 | 🔴 高 | 禁止 |

## 规则 2：风险提示检测

### 必须包含风险提示的场景

| 场景 | 要求 | 风险等级（缺失时） |
|------|------|------------------|
| 涉及投资/理财建议 | 必须包含「投资有风险，入市需谨慎」或同等表述 | 🟡 中 |
| 涉及具体金融产品 | 必须提示该产品的风险等级 | 🟡 中 |
| 涉及收益数据 | 必须标注「历史业绩不代表未来收益」 | 🟡 中 |
| 涉及杠杆/融资 | 必须提示杠杆风险 | 🟡 中 |
| 涉及房地产投资 | 必须提示「房产投资有风险」 | 🟡 中 |

### 标准风险提示语

- 通用：「投资有风险，入市需谨慎。本文内容仅供参考，不构成投资建议。」
- 理财产品：「理财产品过往业绩不代表未来表现，投资需谨慎。」
- 基金：「基金有风险，投资需谨慎。基金管理人管理的基金的过往业绩不构成对未来业绩的保证。」

## 规则 3：合规声明检测

### 合规声明要求

| 场景 | 要求 | 风险等级（缺失时） |
|------|------|------------------|
| 所有财经内容 | 建议包含免责声明 | 🟢 低（建议但不强制） |
| 涉及具体数据分析 | 需标注数据来源 | 🟡 中 |
| 引用机构观点 | 需标注机构名称 | 🟡 中 |
| 涉及预测性内容 | 需标注「个人观点/仅供参考」 | 🟡 中 |

## 规则 4：平台规范检测

### 抖音

| 规则 | 风险等级 |
|------|---------|
| 不得出现微信号/手机号 | 🔴 高 |
| 不得出现二维码导流 | 🔴 高 |
| 不得出现「私信我」「加我」 | 🔴 高 |
| 不得出现竞品平台名称（如「小红书」「快手」） | 🟡 中 |

### 视频号

| 规则 | 风险等级 |
|------|---------|
| 不得出现外部链接导流（公众号文章链接除外） | 🟡 中 |
| 不得出现「加微信」「扫码」 | 🔴 高 |
| 不得出现竞品平台名称 | 🟡 中 |

### 小红书

| 规则 | 风险等级 |
|------|---------|
| 不得出现微信号/手机号 | 🔴 高 |
| 不得出现「私信」「加我」「关注公众号」 | 🔴 高 |
| 不得出现二维码 | 🔴 高 |
| 不得出现「代购」「团购」等商业行为词 | 🟡 中 |
| 正文字数 < 20 字会被判定低质内容 | 🟡 中 |

## 校验结果格式

```json
{
  "passed": true,
  "rules_checked": 4,
  "warnings": [
    {
      "rule": "敏感词检测",
      "level": "中",
      "keyword": "一定",
      "location": "第2段第3句",
      "suggestion": "建议改为「可能」或「预计」"
    }
  ],
  "errors": [
    {
      "rule": "风险提示检测",
      "level": "高",
      "description": "涉及理财建议但未包含风险提示语",
      "suggestion": "文末添加「投资有风险，入市需谨慎」"
    }
  ]
}
```

### 卡片展示规则

- `errors` 为空且 `warnings` 为空 → 展示 `✅ 合规校验通过`
- `errors` 不为空 → 展示 `🔴 合规风险 (N 项高风险)` + 逐条列出
- `warnings` 不为空但 `errors` 为空 → 展示 `⚠️ 合规提示 (N 项建议)` + 逐条列出
- 每条风险/提示含：规则名、风险等级、位置、建议

## 规则维护

- 规则清单需业务侧定期更新（建议每月review一次）
- 新增敏感词或平台规范变化时更新此文件
- 规则引擎需支持动态读取此文件，不需重启即可生效
