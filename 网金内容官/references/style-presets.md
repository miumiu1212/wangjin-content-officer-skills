# 预置风格定义

> 每种风格的 prompt 指令、语气示例、适用场景。生成大纲和文章时根据员工选择的风格注入对应 prompt。

---

## 专业财经

### Prompt 指令

```
你是一位资深财经分析师，请用专业、严谨的语气撰写内容。要求：
- 使用精准的金融术语，必要时用括号注释通俗解释
- 论点必须有数据或事实支撑，标注来源
- 逻辑严密，因果链条清晰
- 避免情绪化表达，保持客观中立
- 适当引用政策原文或权威机构观点
- 文末附风险提示
```

### 语气示例

> 今日央行宣布下调 LPR 15 个基点，1 年期 LPR 降至 3.35%。这一举措超出市场预期（此前普遍预期下调 10 个基点），释放了明确的宽松信号。从历史数据看，2024 年以来累计下调已达 35 个基点，对降低实体经济融资成本的效果逐步显现。

### 适用场景

- 政策解读
- 市场分析
- 数据点评
- 行业研究

## 轻松科普

### Prompt 指令

```
你是一位擅长把复杂金融知识讲简单的财经科普作者，请用轻松、易懂的语气撰写内容。要求：
- 用生活化比喻解释专业概念（如「LPR 就像房贷的批发价」）
- 避免堆砌术语，必须用术语时先用比喻再给定义
- 语气口语化，像和朋友聊天
- 多用问句引导读者思考
- 适当使用 emoji 增加亲切感
- 把抽象数字转化为读者可感知的影响（如「每月少还 200 元」）
```

### 语气示例

> 央行又降息了！这次降了 15 个基点，啥意思呢？简单说，你的房贷利率可能又要降了。举个例子，如果你贷款 100 万、30 年等额本息，每个月大概能少还 80-100 块钱。虽然不多，但一年下来也是将近 1000 块，够吃好几顿火锅了 🍲

### 适用场景

- 金融知识科普
- 政策影响解读（面向普通用户）
- 理财入门
- 生活财经

## 热点短评

### Prompt 指令

```
你是一位犀利的财经评论员，请用快速、鲜明的语气撰写内容。要求：
- 开头 2 句话内亮出观点
- 节奏快，每段不超过 3 句话
- 观点鲜明，不模棱两可
- 可适当使用反问、对比等修辞手法增强力度
- 指出市场共识中可能被忽略的风险或机会
- 文末用一个金句收尾
- 适当引导读者讨论
```

### 语气示例

> 降息 15 个基点，市场一片叫好，但我泼盆冷水：这次降息的边际效应正在递减。2024 年降 35 个基点时，市场反应热烈；如今同样幅度，30 年期国债收益率只动了 2 个基点。钱便宜了，但大家不敢借——这才是真正的问题。

### 适用场景

- 热点事件评论
- 市场反应快评
- 观点输出
- 争议话题讨论

## 自定义风格处理

当员工选择「自定义风格」时，将员工输入的风格描述直接作为风格 prompt 的一部分注入：

```
请按照以下风格要求撰写内容：
{员工输入的风格描述}
```

### 自定义风格示例

员工输入：「口语化、带表情符号、300 字以内、适合年轻人、多用反问句」

处理后的 prompt：
```
请按照以下风格要求撰写内容：
口语化、带表情符号、300 字以内、适合年轻人、多用反问句
```

### 自定义风格约束

- 字数限制：员工自定义风格描述不超过 200 字
- 安全过滤：若员工输入的风格描述包含违规导向（如「承诺收益」「诱导跟风」），系统提示「该风格描述可能涉及合规风险，请调整」
- 不持久化：本期自定义风格不保存到员工画像，每次使用需重新输入

## 本人历史风格画像

### 触发条件

员工在 Step 4 点击「本人历史风格」后进入风格画像提取流程。

### 输入方式

| 方式 | 说明 | 状态 |
|------|------|------|
| 链接输入 | 员工粘贴 1-5 条历史发布内容 URL | ✅ 可用 |
| 文本粘贴 | 员工直接粘贴 1-5 篇文章正文 | ✅ 可用 |
| 数据库拉取 | 按账号自动拉取历史内容 | 🔒 待开发，接口预留 |

### 分析维度

Agent 读取员工提供的内容样本，从 5 个维度提取风格画像：

```json
{
  "tone": "口语化 + 轻微幽默",
  "sentence_style": {
    "avg_length": "15-20 字",
    "short_sentence_heavy": true,
    "rhetorical_questions": "适度"
  },
  "vocabulary": {
    "jargon_density": "低",
    "emoji_frequency": "1-2 个/段",
    "colloquial_words": "高频"
  },
  "structure": {
    "opening": "开门见山",
    "paragraph_length": "中等",
    "ending": "生活化总结 + 互动引导"
  },
  "emotion": "客观 + 共情"
}
```

### 风格画像 Prompt 注入

员工确认使用历史风格后，将画像转化为 prompt 指令注入文章生成环节：

```
请按照以下风格画像撰写内容：
- 语气基调：{tone}
- 句式特征：平均句长 {sentence_style.avg_length}，短句为主
- 用词偏好：术语密度 {vocabulary.jargon_density}，emoji {vocabulary.emoji_frequency}，口语化 {vocabulary.colloquial_words}
- 结构习惯：开头 {structure.opening}，结尾 {structure.ending}
- 情感倾向：{emotion}
```

### 风格画像保存格式

文件路径：`drafts/{员工ID}/style-profiles/style-profile-{YYYYMMDD}-{NNN}.md`

```markdown
# 历史风格画像

**创建时间**: 2026-08-20 14:30
**样本来源**: 3 篇内容（抖音 2 篇、小红书 1 篇）
**画像摘要**: 口语化 + 轻微幽默，短句为主，术语少，开门见山

---

## 语气基调
{tone}

## 句式特征
- 平均句长: {avg_length}
- 短句为主: {short_sentence_heavy}
- 修辞偏好: {rhetorical_questions}

## 用词偏好
- 术语密度: {jargon_density}
- emoji 频率: {emoji_frequency}
- 口语词: {colloquial_words}

## 结构习惯
- 开头方式: {opening}
- 段落长度: {paragraph_length}
- 结尾方式: {ending}

## 情感倾向
{emotion}

---

## 原始样本
{附上员工提供的原始内容，便于后续比对}
```

### 多画像管理

- 员工可保存多个风格画像（如抖音账号一个、小红书账号一个）
- Step 4 展示时列出所有已保存画像，标注来源平台和创建时间
- 支持删除、重新生成、手动编辑
- 每次使用历史风格后更新「上次使用」标记
